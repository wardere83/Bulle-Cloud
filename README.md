🌐 **BulleBrowser** is an open-source Chromium-based browser that runs AI agents natively. Built on BrowserOS, **fully rebranded for Bulle Consulting** — the privacy-first agentic browser alternative to ChatGPT Atlas, Perplexity Comet, and Dia.

🔒 Use your own API keys or run local models with Ollama. Your data never leaves your machine.

## Quick Start

1. **Download and install BulleBrowser:**
   - [Windows (x64 Installer)](https://github.com/wardere83/Bulle-Cloud/releases/latest)
   - [macOS (Universal)](https://github.com/wardere83/Bulle-Cloud/releases/latest)
   - [macOS (Apple Silicon)](https://github.com/wardere83/Bulle-Cloud/releases/latest)
   - [Linux (AppImage)](https://github.com/wardere83/Bulle-Cloud/releases/latest)
   - [Linux (Debian)](https://github.com/wardere83/Bulle-Cloud/releases/latest)

2. Import your Chrome data (optional)

3. Connect your AI provider — use Claude, OpenAI, Gemini, or local models via Ollama and LMStudio.

4. Start automating!

## What Makes BulleBrowser Special

- 🏠 Feels like home — same Chrome interface, all your extensions just work
- 🤖 AI agents that run on YOUR browser, not in the cloud
- 🔒 Privacy first — bring your own keys or run local models with Ollama
- 🔄 Workflows — build repeatable browser automations with a visual graph builder
- ⏰ Scheduled Tasks — run the agent on autopilot, daily or every few minutes
- 💬 LLM Hub — compare Claude, ChatGPT, and Gemini side-by-side on any page
- 🛡️ Built-in ad blocker with uBlock Origin + Manifest V2 support
- 🚀 100% open source under AGPL-3.0

## Releases

All BulleBrowser releases are available on the [Releases page](https://github.com/wardere83/Bulle-Cloud/releases).

To generate a new BulleBrowser release from the latest BrowserOS upstream:
1. Go to **Actions** → **BulleBrowser - Download, Rebrand & Release**
2. Enter the version tag (e.g. `v0.40.1`)
3. Click **Run workflow**
